# Image assets

Drop files into the folder that matches where they'll show up on the site.
Any common web format works (jpg/png/webp) — no need to pre-optimize,
just name things clearly (e.g. `hero.jpg`, `dashboard-01.jpg`).

- `logo/` — brand wordmark, icon mark, favicon source
- `about/` — headshot, hobby/interest photos
- `work/afordal/`, `work/homeasap/`, `work/high5/` — one folder per case
  study: hero shot, decision-block before/after screenshots, system/
  ecosystem visuals
- `projects/eagle-quality/`, `projects/task-yeti/`, `projects/logos/`,
  `projects/illustrations/` — self-directed project work

Once files land in a folder, let me know (or just ask me to wire them up)
and I'll swap the `[IMAGE: placeholder]` boxes on the matching page for
real `<img>` tags.
