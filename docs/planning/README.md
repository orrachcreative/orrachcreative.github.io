# Planning docs

Reference material for building out the portfolio site content. Not part of the
built site — kept here for context across sessions.

## Status by project
- **Afordal** — fully planned. Worksheet filled, case study plan with placeholder
  copy per section, and layout/build decisions recorded. Ready to build.
- **Eagle Quality** — not started. Only the owner questionnaire exists
  (`eagle-quality/eagle-quality-owner-questionnaire.pdf`), meant to be sent to the
  business owner before the case study worksheet can be filled out honestly.
- **HomeASAP** — not started, no material yet.

## Contents
- `afordal/` — filled worksheet, case study plan (placeholder copy per section),
  and layout/build decisions for the Afordal case study.
- `eagle-quality/` — owner discovery questionnaire (unanswered).
- `brand-identity/` — worksheet for the standalone brand identity page, plus two
  wireframe directions: a labeled-sections grid layout, and a continuous
  image-sequence layout inspired by Allan Peters' portfolio.
- `site-structure/` — MVP vs. full site map (home / case studies / brand page / about).
- `case-study-worksheet-blank.md` — blank worksheet template to fill out per
  project (used to produce the Afordal worksheet).
